# SynthCity support

SynthCity is an actively developed sandbox, not a supported commercial release.

- Use the bug-report issue template for reproducible gameplay or browser bugs.
- Use the feature-request template for gameplay and interface proposals.
- Use `SECURITY.md` for vulnerabilities; never report them publicly.

When reporting a bug, include the deployed commit shown by the app, browser and
operating system, city seed or disposable city name, reproduction steps, and a
screenshot when the problem is visual. Do not upload private saves or browser
storage without checking their contents first.

Local saves live in IndexedDB. Clearing site data, using a different browser
profile, or changing origins can make those saves unavailable.
